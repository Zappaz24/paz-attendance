# notes/

Working notes that outlive a chat session or a reboot.

| File | Why |
| --- | --- |
| [`HANDOFF.md`](HANDOFF.md) | **Start here after a reboot.** Current state, commands, verified results, errors already fixed, remaining deliverables. |
| [`DEFENSE-SCRIPT.txt`](DEFENSE-SCRIPT.txt) | Word-by-word run of show for the 100-point defense: 10 parts, timings, what to click, what to say, Q&A bank, phrases to avoid. |

These are notes, not graded documentation. The graded documentation is in
[`../docs/`](../docs/README.md); the rules for changing this repo are in
[`../AGENTS.md`](../AGENTS.md).

No secrets belong in this folder — key values stay in `.env.local`, which is
gitignored.
